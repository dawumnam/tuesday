# 모의 응시의 응시자 페르소나와 AI 도구 LLM은 프로덕션 아바타 GPU를 공유하는 로컬 모델로 돌린다

호출량 대부분을 차지하는 응시자 페르소나와 AI 도구 LLM은 `ml` 서버(프로덕션 아바타와 같은 장비, RTX 6000 Ada 48GB × 2)의 GPU 1장에서 Qwen3.8-27B 4bit를 vLLM으로 서빙하고, 생성·검토·채점·리랭크는 Gemini 3.8 Flash(high)에 둔다. 비용을 줄이고, 채점 에이전트가 자기 모델이 만든 제출물을 채점하는 편향을 줄이기 위해서다. 아바타 생성을 방해하지 않도록 메모리 비율(약 0.35)과 MPS 연산 비율(약 30%)을 제한하며, 로컬 엔드포인트가 없으면 같은 역할을 Gemini로 돌리는 설정 스위치를 둔다.

## Consequences

- 아바타 생성 중 최대 GPU 메모리를 실측하기 전에는 배포하지 않는다.
- 로컬 모델의 한국어 품질과 라이선스는 도입 전에 검증해야 한다.
