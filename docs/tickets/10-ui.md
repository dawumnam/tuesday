# 10 Streamlit screens

Spec: 모듈 → 화면. User stories 1–9, 19, 30–39, 42–47.

- **All UI text is Korean**: labels, buttons, messages, errors, empty states, dashboard axis titles and legends, using GLOSSARY.md terms (e.g. 초안, 상황 후보, 검토 라벨). User-facing errors raised by the service are shown in Korean too.
- Streamlit app calling only `TaskDesignService`. Top staff selector (2 fixed staff, no login).
- Screens: 입력 폼, 상황 후보 선택 (with referenced tasks, regenerate button), 진행 (live stage + per-persona status, polls `get_draft`; resumable by draft id / list of my drafts), 검토 (single-screen edit of 상황/지시문/첨부 자료/채점 기준, mock exam scoreboard + transcripts + round history + failure report alongside, labels required before confirm/reject, own drafts blocked), 대시보드 (metrics + per-draft trace links).
- Long runs execute in a background thread/process so the UI can be closed and reopened.
- Human-time: a small JS component reporting visible/active intervals → `record_activity`.
- Test: a smoke test with Streamlit's `AppTest` per screen against FakeGateway; manual run via `make up`.
